# Triage 라벨

스킬들은 5개의 표준 트리아지 역할을 기준으로 말한다. 이 파일은 그 역할을
이 저장소 이슈 트래커에서 실제로 쓰는 라벨 문자열에 매핑한다.

| mattpocock/skills 라벨 | 이 트래커의 라벨 | 의미 |
|---|---|---|
| `needs-triage` | `needs-triage` | 유지보수자가 평가해야 함 |
| `needs-info` | `needs-info` | 보고자의 추가 정보 대기 |
| `ready-for-agent` | `ready-for-agent` | 스펙 완료, 에이전트가 바로 착수 가능 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 함 |
| `wontfix` | `wontfix` | 처리하지 않음 |

스킬이 역할을 언급하면(예: "AFK-ready 트리아지 라벨 적용") 이 표의 라벨 문자열을 사용한다.

우측 열을 수정해 실제 사용 어휘에 맞출 수 있다.
